# ansari2016coders - Ansari et al., 2016, CodERS: A Hybrid Recommender System for an E-learning System

- opened_on: 2026-09-20   source: 10.1109/ICSPIS.2016.7869884   type: conference   verified: yes
- Access: access=full text (local PDF); author copy with the ICSPIS 2016 header; IEEE page not opened; pages and DOI matched from Crossref
- Problem: Recommendation inside a programming e-learning platform, tailored to user behaviour.
- Method: Four components; the engine picks CF, CBF or a combination dynamically (PDF pp.2-3).
- Data and domain: Inputs listed: user code patterns, course/step completion duration, questions and implicit feedback, social data (PDF p.3). Test: 12 random users, four recommendations each (PDF p.4).
- Metrics and results (with the task each measures): Acceptance rates in Fig. 7 and satisfaction 1-5 in Fig. 8 with no numeric values in the text; authors call the results satisfactory (PDF p.4).
- Limitations stated by the authors and noticed by me: Authors: implementation still being finalised; the test was mainly content-based with limited user data (PDF p.4).
- My reading (what it means for this thesis): A design paper. Its self-described 'context-specific' hybrid is platform-specific rather than context-aware in the sense of location, time or company.
